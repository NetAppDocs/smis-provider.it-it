= Problemi con la libreria di runtime
:allow-uri-read: 
:icons: font
:imagesdir: ./media/
:pp: &#43;&#43;


[role="lead"]
NetApp SMI-S Provider potrebbe riscontrare problemi con le librerie di runtime su Windows. Installa il pacchetto ridistribuibile di Microsoft Visual C{pp} necessario per risolverli.

* *Problema*
+
Si verificano problemi con la libreria runtime.

* *Azione correttiva*
+
Installare Microsoft Visual C{pp} 2010 Redistributable Package (x86) da www.microsoft.com.
